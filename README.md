# Lab 4: Control Units

## List of Exercises

### ex4.1.1 Datapath Analysis
- **Description**: Analysis of a simplified **DLX datapath** consisting of three pipeline stages. The design includes a register file, ALU, memory, and control signals for managing the pipeline flow.

### ex4.2.1 Hardwired Control Unit
- **Description**: Design and implementation of a **Hardwired Control Unit** for the simplified DLX datapath. The control unit generates control signals through a look-up table, enabling pipelined execution of instructions.

### ex4.3.1 FSM Control Unit
- **Description**: Implementation of a **Finite State Machine (FSM) Control Unit** for the simplified DLX datapath. The FSM manages instruction execution sequentially, with states corresponding to the fetch, decode, and execute phases.

### ex4.4.1 Microprogrammed Control Unit
- **Description**: Design of a **Microprogrammed Control Unit** integrating a microcode memory to generate control signals. The execution of instructions occurs sequentially over multiple clock cycles.
